# Test

**Назначение:** веб-приложение с набором небольших инструментов в одном интерфейсе.

## Что доступно пользователю

В боковом меню сейчас доступны три раздела:

| Раздел | URL | Состояние |
|---|---|---|
| Идеи стартапов | `/tool-1` | Рабочая первая версия: список идей с раскрывающимся описанием |
| Инструмент 2 | `/tool-2` | Каркас для будущего инструмента |
| Инструмент 3 | `/tool-3` | Каркас для будущего инструмента |

### Идеи стартапов

Первый раздел показывает идеи стартапов из базы данных. У каждой идеи есть заголовок и описание; по нажатию на заголовок описание можно развернуть и свернуть.

Сейчас в базе находятся три демонстрационные идеи. Они нужны для наполнения интерфейса и могут быть заменены или дополнены позже.

### Иконка сайта

Добавлен фирменный favicon с прозрачным фоном. Подключены favicon, мобильная иконка и web manifest через `public/favicon.ico`, `public/favicon-96.png` и `public/site.webmanifest`.

## Технологии

- Laravel — серверная часть, Eloquent и Blade-представления.
- SQLite — текущая база данных.
- Vite — сборка JavaScript и CSS для браузера.
- PHPUnit — автоматические тесты.
- GitHub Actions — проверка проекта, сборка frontend и деплой.

## Интерфейс

Общие элементы интерфейса находятся в Blade-компонентах. JavaScript и CSS не встраиваются в страницы напрямую: они хранятся в соответствующих ресурсах и проходят через Vite.

Первый раздел использует нативный раскрывающийся элемент браузера, поэтому открытие и закрытие описаний работает без отдельного inline-JavaScript.
