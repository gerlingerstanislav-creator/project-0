# Test

**Назначение:** веб-приложение с набором небольших инструментов в одном интерфейсе.

## Что доступно пользователю

В боковом меню сейчас доступны три раздела:

| Раздел | URL | Состояние |
|---|---|---|
| Инструмент 1 | `/tool-1` | Каркас для будущего инструмента |
| Инструмент 2 | `/tool-2` | Каркас для будущего инструмента |
| Инструмент 3 | `/tool-3` | Каркас для будущего инструмента |

Главная страница доступна по адресу `/`.

Разделы используют общую навигацию. На мобильных устройствах боковое меню превращается в выезжающее меню с кнопкой открытия и закрытия.

## Технологии

- Laravel — серверная часть и Blade-представления.
- Vite — сборка JavaScript и CSS для браузера.
- PHPUnit — автоматические тесты.
- GitHub Actions — проверка проекта, сборка frontend и деплой.

## Структура пользовательского интерфейса

Общие элементы интерфейса находятся в Blade-компонентах. JavaScript и CSS не встраиваются в страницы напрямую: они хранятся в соответствующих ресурсах и проходят через Vite.
