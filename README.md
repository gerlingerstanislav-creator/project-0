# STools

**Назначение:** веб-приложение с набором небольших инструментов в одном интерфейсе.

## Авторизация и роли

Приложение использует авторизацию по логину и паролю. В базе есть два начальных аккаунта: `admin` с ролью админа и `editor` с ролью редактора.

Поддерживаются три роли:

| Роль | Возможности |
|---|---|
| Админ | Просмотр инструментов и редактирование идей стартапов |
| Редактор | Просмотр инструментов и редактирование идей стартапов |
| Просмотр | Просмотр инструментов без редактирования |

После входа в левом меню отображаются логин, роль и кнопка выхода. Авторизация не обязательна для просмотра сайта: неавторизованный пользователь может открывать инструменты, но не видит и не может использовать редактирование идей. Страница `/login` используется только для входа в аккаунт.

## Что доступно пользователю

В боковом меню сейчас доступны три раздела:

| Раздел | URL | Состояние |
|---|---|---|
| Идеи стартапов | `/tool-1` | Рабочая версия: список идей с раскрывающимся описанием и редактированием для админа и редактора |
| Инструмент 2 | `/tool-2` | Мини-игра «Степан, выпей»: бутылка и стакан с интерактивным наливанием и выпиванием |
| Инструмент 3 | `/tool-3` | Каркас для будущего инструмента |

Страницы помечены идентификаторами `Page 01`, `Page 02`, `Page 03`; идентификатор размещается в правом нижнем углу карточки страницы.

### Идеи стартапов

Первый раздел показывает идеи стартапов из базы данных. У каждой идеи есть заголовок и описание; по нажатию на заголовок описание можно развернуть и свернуть.

Карандаш и элементы редактирования видят только админ и редактор. Для них название и описание становятся редактируемыми, а кнопка «Сохранить» записывает изменения в базу данных. Пользователь с ролью «Просмотр» может только просматривать идеи.

Сейчас в базе находятся три демонстрационные идеи. Они нужны для наполнения интерфейса и могут быть заменены или дополнены позже.

### Мини-игра «Степан, выпей»

На второй странице размещена мини-игра с бутылкой пива и стаканом. При наведении на бутылку появляется «Налить», а при нажатии бутылка наклоняется и в стакан добавляется одна порция. В стакане максимум четыре порции (четыре глотка), при этом в бутылке визуально остаётся половина пива. При наведении на стакан появляется «Выпить», а при нажатии стакан опустошается.

### Иконка сайта

Добавлен фирменный favicon с прозрачным фоном. Подключены favicon, мобильная иконка и web manifest через `public/favicon.ico`, `public/favicon-96.png` и `public/site.webmanifest`.

## Технологии

- Laravel — серверная часть, Eloquent и Blade-представления.
- SQLite — текущая база данных.
- Vite — сборка JavaScript и CSS для браузера.
- PHPUnit — автоматические тесты.
- GitHub Actions — проверка проекта, сборка frontend и деплой.

## Интерфейс

Общие элементы интерфейса находятся в Blade-компонентах. JavaScript и CSS не встраиваются в страницы напрямую: они хранятся в соответствующих ресурсах и проходят через Vite.

Первый раздел использует нативный раскрывающийся элемент браузера, а редактирование выполняется отдельным JS-кодом через PATCH-запрос к Laravel.
