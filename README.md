# STools

**STools** — веб-приложение на Laravel с набором небольших инструментов в одном интерфейсе.

## Что доступно пользователю

В боковом меню доступны пять разделов:

1. **Идеи стартапов** — список идей из SQLite. Для пользователей с ролью **admin** или **editor** доступно редактирование названия и описания прямо в карточке; остальные пользователи могут только просматривать идеи.
2. **Степан, выпей** — небольшая интерактивная мини-игра: бутылка наполняет стакан, а стакан рассчитан на четыре глотка.
3. **Инструмент 3** — текущий каркас третьего инструмента, готовый для дальнейшей реализации.
4. **Менеджерские шпаргалки** — практические материалы из базы данных, открывающиеся в раскрывающихся карточках.
5. **Горнолыжные курорты** — раздел `/weather` с данными по пяти российским курортам.

### Горнолыжные курорты

На странице `/weather` доступны:

- Шерегеш;
- Красная Поляна;
- Роза Хутор;
- Газпром (Лаура + Альпика);
- Большой Вудъявр (Кировск).

Для каждого курорта показываются текущая температура, статус **«Активен» / «Не активен»**, ориентировочные даты сезона, семидневный прогноз и официальные веб-камеры. Если для камеры доступен безопасный для встраивания официальный плеер, трансляция открывается прямо в карточке; иначе показывается ссылка на официальный источник. Для Шерегеша доступен встроенный официальный плеер первой камеры.

Погодные данные загружаются из Open-Meteo. Прогноз обновляется автоматически на стороне браузера; если внешний погодный сервис временно недоступен, страница продолжает работать без текущей температуры.

## Авторизация и доступ

- `/login` — вход по имени пользователя и паролю.
- Просмотр основных инструментов доступен без авторизации.
- Редактирование идей стартапов защищено авторизацией и ролью: только **admin** и **editor** получают элементы редактирования.
- Выход из аккаунта доступен авторизованным пользователям.

## Технологии

- **Laravel 13** — серверная часть, маршруты, контроллеры, Eloquent и Blade.
- **PHP 8.3+**; CI и production настроены на PHP 8.5.
- **SQLite** — текущая база данных.
- **Vite 7** — сборка frontend.
- **Tailwind CSS 4** — используется вместе с существующими CSS-стилями проекта.
- **JavaScript** — интерактивное поведение страниц.
- **PHPUnit 12** — автоматические feature-тесты.
- **GitHub Actions** — тестирование, frontend-сборка, упаковка и деплой на Ubuntu VPS.

## Структура проекта

- `app/Http/Controllers/` — контроллеры.
- `app/Models/` — Eloquent-модели.
- `database/migrations/` — схема базы данных.
- `database/seeders/` — исходные данные для идей, пользователей и менеджерских шпаргалок.
- `resources/views/` — Blade-представления.
- `resources/js/app.js` — основная точка входа JavaScript.
- `resources/css/app.css` — основные стили.
- `routes/web.php` — веб-маршруты.
- `tests/Feature/` — feature-тесты.
- `vite.config.js` — конфигурация Vite.
- `AGENTS.md` — единые правила разработки и работы AI-агента с проектом.
- `readmeGPT.md` — информация о возможностях интеграции с GitHub.

Общие элементы интерфейса находятся в Blade-компоненте `resources/views/components/layout.blade.php`. JavaScript и CSS не встраиваются в страницы напрямую: они хранятся в соответствующих ресурсах и проходят через Vite.

## Локальный запуск

Установить зависимости:

```bash
composer install
npm install
```

Подготовить окружение и SQLite:

```bash
cp .env.example .env
touch database/database.sqlite
php artisan key:generate
php artisan migrate --seed
```

Запустить frontend в режиме разработки:

```bash
npm run dev
```

Для production-сборки:

```bash
npm run build
```

Тесты:

```bash
vendor/bin/phpunit
```

## CI/CD

GitHub Actions выполняет на `main`:

1. PHP-тесты на PHP 8.5.
2. Установку npm-зависимостей и production-сборку Vite.
3. Упаковку release-архива.
4. Деплой на Ubuntu VPS после успешных тестов и frontend-сборки.
5. HTTP health check после деплоя.

Подробные правила разработки, проверки перед сборкой, работы с README, коммитами и ошибками деплоя находятся в `AGENTS.md`.
