# STools

**Назначение:** веб-приложение с набором небольших инструментов в одном интерфейсе.

## Что доступно пользователю

В боковом меню доступны пять разделов: идеи стартапов, инструмент 2, инструмент 3, «Менеджерские шпаргалки» и «Погода».

### Менеджерские шпаргалки

Раздел `/manager-cheat-sheets` содержит 15 практических шпаргалок из раздела «Шпаргалки» подпроекта manager-tools репозитория ideas. Материалы открываются в раскрывающихся карточках по аналогии с разделом «Идеи для стартапов».

## Технологии

- Laravel — серверная часть, Eloquent и Blade-представления.
- SQLite — текущая база данных.
- Vite — сборка JavaScript и CSS для браузера.
- PHPUnit — автоматические тесты.
- GitHub Actions — проверка проекта, сборка frontend и деплой.

## Интерфейс

Общие элементы интерфейса находятся в Blade-компонентах. JavaScript и CSS не встраиваются в страницы напрямую: они хранятся в соответствующих ресурсах и проходят через Vite.


### Погода

Раздел `/weather` показывает актуальные данные и прогноз на сегодня и завтра для Ульяновска, Москвы и Мюнхена. Погодные данные загружаются из Open-Meteo и обновляются автоматически каждую минуту. Для каждого города показываются две строки: сегодня и завтра — дата, температура, состояние погоды и вероятность осадков; для городов с доступной трансляцией используется актуальная веб-камера.
