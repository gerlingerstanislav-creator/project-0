# project-0

**project-0** — веб-приложение на Laravel 13 с небольшими инструментами в едином SPA-интерфейсе.

**Сайт:** https://project-0.duckdns.org

## Доступ и авторизация

Главная страница `/` доступна без авторизации и содержит презентационный экран и навигацию по разделам проекта. Все инструменты, тесты, дизайн-система и push-endpoints защищены middleware `auth`.

В системе три роли: **admin**, **moderator** и **user**. Администратор и модератор могут редактировать идеи стартапов. Начальный пользователь `user` создаётся сидером с паролем `12345678`.

## Возможности

После авторизации в боковом меню доступны следующие разделы:

1. **Идеи стартапов** — список идей из SQLite. Роли **admin** и **moderator** могут редактировать название и описание.
2. **Степан, выпей** — интерактивная мини-игра с бутылкой и стаканом.
3. **Менеджерские шпаргалки** — материалы из базы данных в раскрывающихся карточках.
4. **Горнолыжные курорты** — `/ski-resort` с погодой, прогнозом и веб-камерами пяти российских курортов.
5. **Новости** — агрегатор RSS-лент с категориями, значимостью, персональной релевантностью и пользовательской обратной связью. Новости показываются на языке источника.
6. **Тесты** — `/tests` для проверки PWA и push-уведомлений.
7. **Конструктор расписаний** — `/cron-scheduler`: конструктор cron-выражений с валидацией, описанием и ближайшими запусками.
8. **Check IP** — `/check-ip`: диагностический паспорт IPv4/IPv6. Показывает тип и scope адреса, reverse DNS, decimal/hex/binary представления и для публичных IP получает регистрационные данные, диапазон, контакты, события и raw JSON через RDAP. Внешний RDAP-запрос выполняется сервером с таймаутом; endpoint ограничен rate limit.
9. **Дизайн-система** — каталог компонентов и визуальных правил; доступен admin и moderator.
10. **Обучение event-менеджера** — `/event-manager-training`: практическая программа подготовки специалиста к самостоятельной разработке, организации и проведению внутренних, корпоративных и частных мероприятий разной сложности.

Публичные страницы — только `/` и `/login`. Остальные разделы требуют авторизации.

### Новости

Новостная страница собирает RSS из TechCrunch, Ars Technica, Habr, Hacker News, The Guardian и BBC. Запросы выполняются параллельно с короткими таймаутами, а результат кэшируется на 5 минут.

Лента разделяет **значимость** и **релевантность**: значимость оценивается по признакам изменения рынка, продукта, регулирования, безопасности и другим сигналам, а релевантность — по базовому профилю интересов и пользовательской обратной связи. «Больше такого» и «Не интересно» корректируют релевантность похожих материалов, а «Скрыть источник» исключает источник из персональной ленты. Пользователь может выбрать категории и минимальный порог значимости; эти фильтры сохраняются в профиле пользователя. Заголовки и описания выводятся в оригинале из RSS-источника.

### Обучение event-менеджера

Страница обучения построена как практический маршрут на 12–14 недель из восьми модулей: роль event-менеджера и бриф, концепция и программа, бюджет, площадка и технический продакшен, подрядчики и команда, гостевой сервис, риски и проведение, post-event анализ. Программа завершается тремя проектами растущей сложности и финальной аттестацией на реальном мероприятии. Отдельно показаны рабочие документы, которые специалист должен уметь собирать, и матрица навыков от junior до самостоятельного ведения сложных проектов.

### Горнолыжные курорты

Доступны Шерегеш, Красная Поляна, Роза Хутор, Газпром (Лаура + Альпика) и Большой Вудъявр (Кировск). Погода загружается из Open-Meteo в браузере. Камеры поддерживают официальные видео-плееры, изображения и внешние страницы камер.

## Архитектура

Frontend построен на **Inertia.js + Vue 3**; Blade используется только как минимальный HTML-shell. Laravel отвечает за маршруты, авторизацию, данные и серверные mutations. Vue-страницы находятся в `resources/js/pages/`, общий интерфейс — в `resources/js/layouts/`, точка входа — `resources/js/app.js`, стили — в `resources/css/`.

### Design system

Интерфейс использует внутреннюю дизайн-систему на базе semantic design tokens и переиспользуемых Vue-компонентов. Основные компоненты находятся в `resources/js/components/ui/`, токены и базовые стили — в `resources/css/design-system/`. Каталог компонентов доступен на `/design-system`.

PWA и Web Push уже реализованы: `public/site.webmanifest`, `public/sw.js`, `resources/js/pwa.js`, модель и миграция PushSubscription и защищённые endpoints `/push/subscriptions`. Разрешение на уведомления запрашивается по действию пользователя. Production-деплой автоматически генерирует VAPID-ключи на VPS, если они ещё не заданы.

## Локальный запуск

~~~bash
composer install
npm install
cp .env.example .env
touch database/database.sqlite
php artisan key:generate
php artisan migrate --seed
npm run dev
~~~

Production-сборка: `npm run build`. Тесты: `vendor/bin/phpunit`. Тестовый набор использует SQLite в памяти и автоматически применяет миграции через `RefreshDatabase`.

## CI/CD

Push в `main` запускает два workflow: CI проверяет PHPUnit и production-сборку Vite, а отдельный Deploy workflow повторно выполняет тесты, собирает production release и выкладывает его на Ubuntu VPS без использования GitHub Artifacts. После выкладки выполняются smoke checks сайта.

### Диагностика production БД

Для безопасной проверки production SQLite добавлена read-only диагностика `php artisan project:db-diagnostics --json`. Она показывает состояние соединения, таблицы, миграции, роли, количество основных записей и состояние Web Push без вывода секретов.
