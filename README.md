# Test

Веб-приложение с набором небольших инструментов в едином интерфейсе.

## Разделы

В боковом меню доступны три раздела:

- **Инструмент 1** — подготовленный раздел для первого инструмента.
- **Инструмент 2** — подготовленный раздел для второго инструмента.
- **Инструмент 3** — подготовленный раздел для третьего инструмента.

Сейчас эти разделы представляют собой каркас интерфейса для дальнейшей реализации инструментов.

## Интерфейс

Приложение рассчитано на работу на компьютере и мобильных устройствах. На мобильных экранах боковая навигация открывается отдельным меню.

## Технологии

Проект построен на Laravel с использованием Vite для frontend-ресурсов.

## Документация для разработки

Правила работы с Laravel находятся в [LARAVEL_RULES.md](LARAVEL_RULES.md), а общие правила проекта — в [PROJECT.md](PROJECT.md).
