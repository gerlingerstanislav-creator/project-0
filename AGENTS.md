# Правила работы с проектом

## Отчёт после push

После каждого push изменений в ветку в итоговом отчёте необходимо отдельной строкой указывать статус документации:

**Документация обновлена:** да — документация проекта приведена в соответствие с внесёнными изменениями.

Если в конкретном изменении документация действительно не требовала изменений, это нужно явно указать вместо утверждения об обновлении.

Это правило относится к каждому push, который выполняется в рамках работы над проектом.
