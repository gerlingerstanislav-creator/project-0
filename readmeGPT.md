# Возможности работы с GitHub

Я могу выполнять с репозиториями и их содержимым следующие действия:

## Репозитории
- Просматривать информацию о репозитории.
- Просматривать доступные мне репозитории.
- Искать репозитории.
- Проверять права доступа к репозиторию.

## Файлы и код
- Просматривать содержимое файлов.
- Создавать новые текстовые файлы.
- Редактировать существующие текстовые файлы.
- Удалять файлы.
- Искать код и файлы по содержимому.
- Просматривать изменения отдельных файлов и коммитов.

## Ветки и коммиты
- Создавать ветки.
- Создавать коммиты.
- Сравнивать коммиты и ветки.
- Перемещать указатель ветки на нужный коммит.
- Создавать Git-объекты (blob/tree) для работы с содержимым репозитория.

## Pull Request
- Создавать Pull Request.
- Просматривать Pull Request и его изменения.
- Просматривать изменённые файлы и diff.
- Оставлять комментарии.
- Отвечать на комментарии ревью.
- Создавать ревью.
- Запрашивать ревьюеров.
- Снимать запросы на ревью.
- Помечать Pull Request как готовый к ревью или возвращать в Draft.
- Одобрять/комментировать изменения или запрашивать доработки через ревью.
- Разрешать и возвращать review threads.
- Добавлять и удалять реакции.
- Добавлять и удалять labels.
- Назначать и снимать assignees.
- Сливать Pull Request.
- Включать auto-merge.

## Issues
- Создавать Issues.
- Просматривать Issues и комментарии.
- Редактировать Issues.
- Назначать исполнителей.
- Добавлять и удалять labels.
- Комментировать Issues.
- Блокировать и разблокировать обсуждения.
- Добавлять и удалять реакции.

## GitHub Actions
- Просматривать workflow runs.
- Просматривать jobs и их шаги.
- Просматривать логи jobs.
- Просматривать и скачивать artifacts.
- Повторно запускать отдельные jobs.
- Повторно запускать все упавшие jobs.
- Проверять статусы CI для коммитов.

## Анализ
- Анализировать код и структуру репозитория.
- Проверять diff между коммитами.
- Изучать историю коммитов.
- Помогать находить ошибки и предлагать исправления.

> Конкретные действия зависят от прав, предоставленных подключённому GitHub-доступу, и от ограничений GitHub API.
