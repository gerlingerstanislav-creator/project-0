# «Путь без преград» — самостоятельный сайт для Timeweb

Эта сборка превращает существующую страницу `resources/js/pages/PutBezPregrad.vue` в самостоятельный статический сайт, не требующий Laravel, PHP, базы данных или Inertia.

## Как получить файлы

1. Откройте GitHub → Actions → **Build Timeweb landing** в ветке `timeweb-landing`.
2. Скачайте артефакт **put-bez-pregrad-timeweb** (ZIP) из успешного запуска workflow.
3. Распакуйте ZIP и загрузите **его содержимое**, а не сам ZIP и не дополнительную вложенную папку, в `public_html` хостинга Timeweb.
4. Удалите штатный `public_html/index.htm` (заглушка Timeweb); каталог `cgi-bin` можно оставить.
5. Сначала проверьте сайт по техническому домену `bpreg.tw1.ru`.
6. В Timeweb привяжите `путь-без-преград73.рф` к существующему «Основному сайту», проверьте DNS, выпустите бесплатный Let's Encrypt и включите редирект HTTPS.

## Как работает сборка

Workflow копирует исходную страницу Vue и её локальные компоненты. Скрипт `scripts/build-timeweb.mjs` удаляет только Inertia-обёртку Head (метаданные перенесены в `timeweb/index.html`) и копирует исключительно изображения лендинга. Стили берутся из существующей CSS-системы проекта. Vite формирует HTML, JS, CSS и изображения в `dist-timeweb/`.

Для ручной сборки в корне репозитория:

```bash
npm install
node scripts/build-timeweb.mjs
npx vite build --config vite.config.timeweb.js
```

При изменении контента страницы на `main` нужно обновить ветку `timeweb-landing` из `main` и запустить сборку. До настройки автоматической загрузки на хостинг обновление производится загрузкой свежих файлов.
